Found a Bug?

If something isn't working correctly, report it through the official GitHub Issue Tracker.

Before Reporting
  • What's the problem?
  • What causes it to happen?
  • What should happen instead?
  • What actually happens?
  • Add a screenshot or relevant details if you can
Check Known Issues → Go to Report Issue →
Important
The app won't create a GitHub Issue automatically. Tapping the button above takes you to GitHub's official issue page, where you submit the report yourself using your own GitHub account.
