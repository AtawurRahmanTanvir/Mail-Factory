Everything you need to know about Mail Factory

HOW TO USE
1
Go to Single or Batch Generator
Choose the generator you want to use.
Find both modes from the Engine tab at the bottom of the app.
2
Enter your preferences
Fill in the required fields and set options.
Set length, character types, or domain — whatever this generator needs.
3
Generate
Tap the generate button to create results.
Results appear instantly in the list below — no waiting, no network needed.
4
Copy & Use
Copy the results and use them anywhere.
Tap one result to copy it, or use Copy All for the whole batch.
FEATURES
Email Generator
Generate unlimited unique email addresses.
Password Generator
Create strong and secure passwords.
Batch Generation
Generate multiple results at once.
One-Tap Copy
Copy single items and all results instantly.
TIPS
Use longer lengths for more secure passwords.
Batch generation is faster for large lists.
All results are generated locally on your device.
FAQ
Q
Is my data stored anywhere?
No — every email and password is generated and processed locally on your device. Nothing is uploaded to a server.
Q
Are the results unique?
Yes, each result is freshly generated and not reused between runs.
Q
Can I use these emails anywhere?
Yes, they're standard, valid addresses usable wherever an email is accepted.
Q
Is this app free to use?
Yes, all core features are free to use.
